If YELLOW:
Patient successfully entered.
If DARK GREEN:
Patient successfully selected.
If YELLOW: Device successfully entered. If DARK GREEN: Device successfully selected.

  • Coordinator: When there is an act msg or pan msg waiting for 'node 0' (the coordinator);

  • Curr Pan Patient: When there is a pan msg waiting for a node belonging to a patient; also evaluates the patient's rules;

  • Curr Act Patient: When there is an act msg waiting for a node belonging to a patient;

  • Curr Device Pan: Always simulates a unit of time on the device and generates a new panel update;

  • Curr Device Act: When there is an act msg waiting for a node belonging to a device;

  • Edited a Display: Do Coordinator;

  • Executing an action from patient layer: Do Curr Device Pan of corresponding device → Curr Pan Patient corresponding to the patient → Coordinator;

  • Executing an action from coordinator: Do Curr Act Patient → Curr Device Act → Curr Device Pan → Curr Pan Patient → Coordinator;

  • Rule triggered: Do Curr Pan Patient to evaluate its rules. If an alarm is triggered → Coordinator → Curr Device Pan → Curr Pan Patient → Coordinator;

  • Executing an action from device layer: Do Curr Device Pan of corresponding device → Curr Pan Patient corresponding to the patient → Coordinator;
